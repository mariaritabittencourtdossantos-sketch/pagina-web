# pagina-web 
Esse blog foi criado para introduzir uma análise do Homem-Aranha ou Peter Parker com os conceitos de persona e indivduação do psquiatra e psicoterapeuta Carl Jung.O blog busca mostrar que Peter Parker pode ser interpretado como um personagem que enfrenta conflitos relacionados à sua identidade e aos diferentes papéis que desempenha.
Tecnologias utilizadas

O projeto foi desenvolvido utilizando:
HTML5 — estrutura e organização da página;
CSS3 — estilização e aparência do blog;
JavaScript — interação do botão de curtida;
YouTube — vídeo utilizado como inspiração para a pesquisa.

É o arquivo principal do projeto. Ele contém:

Cabeçalho do blog;
Título e subtítulo;
Informações sobre a publicação;
Artigo principal;
Imagens;
Vídeo incorporado do YouTube;
Botão de curtida;
Rodapé.

style.css
Arquivo responsável pela aparência visual do blog, incluindo cores, fontes, tamanhos, espaçamentos, imagens e organização dos elementos.

script.js
Arquivo responsável pela parte interativa do site, como o funcionamento do botão "Curtir" e do contador de curtidas.

Imagens
O projeto utiliza três imagens relacionadas ao Homem-Aranha para complementar visualmente o conteúdo do artigo. 


interatividade
O blog possui um botão de curtida:
❤️ Curtir 0
Ao clicar no botão, o JavaScript altera o contador de curtidas, tornando a página mais interativa.

🎥 Vídeo
O site também apresenta um vídeo incorporado do YouTube que serviu como inspiração para estabelecer a relação entre Peter Parker e a filosofia de Carl Jung. O vídeo é de autoria do canal: "Kyeøruh"
